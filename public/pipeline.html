Request Lifecycle

Click any stage to see the technical details

01

HTTP POST Request

Frontend → Backend
+

When you click "Analyze", the browser fires a fetch() call to the Flask backend. The text you entered is serialized as JSON and sent via an asynchronous POST request.

  • Endpoint (Sentiment): /api/analyze-sentiment
  • Endpoint (Fake News): /api/detect-fakenews
  • Method: POST
  • Content-Type: application/json
  • Payload: { "text": "your input..." }
app.js — fetch call
const res = await fetch('/api/analyze-sentiment', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({ text })
});
const data = await res.json();
02

Flask Route Handler

app.py — API Layer
+

Flask receives the request and routes it to the decorated function. The handler extracts the JSON body, validates the input, and delegates to the ML pipeline.

  • Framework: Flask 3.1.1
  • Validation: Checks for empty text, model availability
  • Error Handling: Returns 400 (bad input) or 503 (model not loaded)
  • WSGI Server: Gunicorn (production) / Werkzeug (dev)
app.py — route handler
@app.route('/api/analyze-sentiment', methods=['POST'])
def analyze_sentiment():
    data = request.get_json()
    text = data.get('text', '').strip()

    if not text:
        return jsonify({'error': 'No text provided'}), 400

    # → proceeds to NLP pipeline...
03

Text Cleaning & Normalization

NLP — Step 1
+

The raw text is cleaned to remove noise that would confuse the ML model. All text is lowercased and non-alphabetic characters (numbers, punctuation, special symbols) are stripped.

Input
"This product is AMAZING!!! 5/5 stars ⭐"
→
Output
"this product is amazing stars"
preprocess_text() — cleaning
def preprocess_text(text):
    text = str(text).lower()
    text = re.sub(r'[^a-zA-Z\s]', '', text)
    # Result: only lowercase letters + spaces
04

Tokenization & Stopword Removal

NLP — Step 2
+

Text is split into individual tokens (words). Common English words that carry no sentiment meaning — like "is", "the", "a", "this" — are removed using NLTK's stopword list (179 words).

Tokens
["this", "product", "is", "amazing", "stars"]
→
Filtered
["product", "amazing", "stars"]
  • Library: nltk.corpus.stopwords
  • Language: English (179 stop words)
  • Purpose: Reduce noise, focus on meaningful words
preprocess_text() — tokenize & filter
tokens = text.split()
stop_words = set(stopwords.words('english'))
tokens = [word for word in tokens
          if word not in stop_words]
# Removes: "this", "is", etc.
05

Lemmatization

NLP — Step 3
+

Each remaining token is reduced to its dictionary root form (lemma) using NLTK's WordNet Lemmatizer. This normalizes word variations so the model treats "running", "ran", and "runs" as the same concept.

Tokens
["products", "amazing", "stars"]
→
Lemmatized
["product", "amazing", "star"]
  • Library: nltk.stem.WordNetLemmatizer
  • Difference from Stemming: Produces valid dictionary words
preprocess_text() — lemmatize
lemmatizer = WordNetLemmatizer()
tokens = [lemmatizer.lemmatize(word)
          for word in tokens
          if word not in stop_words]
return ' '.join(tokens)
# Final: "product amazing star"
06

TF-IDF Vectorization

Feature Engineering
+

The cleaned text is converted into a numerical feature vector using the pre-fitted TF-IDF vectorizer. Each dimension represents a word (unigram) or word pair (bigram) weighted by how important it is across all training documents.

Clean Text
"product amazing star"
→
Sparse Vector
[0, 0, 0.42, ..., 0.71, 0, 0.58]
(5000 dimensions)
  • Max Features: 5,000
  • N-gram Range: (1, 2) — unigrams + bigrams
  • TF: Term Frequency — how often a word appears in this text
  • IDF: Inverse Document Frequency — rarity across all docs
  • Library: sklearn.feature_extraction.text.TfidfVectorizer
app.py — vectorize at prediction time
# Pre-fitted vectorizer loaded from .pkl
# tfidf_sentiment.pkl or tfidf_fakenews.pkl

clean = preprocess_text(text)

# Sparse matrix, most values = 0

08

JSON API Response

Backend → Frontend
+

Flask serializes the prediction, confidence score, probability distribution, and the processed text into a JSON response. The frontend then renders this data with animated gauges and visual badges.

  • Status: 200 OK
  • Content-Type: application/json
  • Latency: ~50–150 ms (including NLP + inference)
Response payload
return jsonify({
    "sentiment": "positive",
    "confidence": 92.47,
    "probabilities": {
        "positive": 92.47,
        "negative": 7.53
    },
    "processed_text": "product amazing star"
})

Model Training

How the ML models were trained offline before deployment

T1

Load Dataset

CSV files from /data/ — product reviews (sentiment) and labeled news articles (fake news)

T2

Preprocess All Rows

Apply the same NLP pipeline (clean → tokenize → stopwords → lemmatize) to every training sample

T3

Fit TF-IDF Vectorizer

Learn vocabulary and IDF weights from training data, produce 5000-dim sparse feature matrix

T4

Train & Evaluate Models

80/20 train-test split. Train LR, NB, SVM, DT, RF. Compare F1-weighted scores. Pick the best.

T5

Serialize with Joblib

Save best model + fitted TF-IDF vectorizer as .pkl files to /models/
